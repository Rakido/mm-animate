# Transition de couleurs

import NxParallaxColorTransitions from '../../components/NxParallaxColorTransitions'

## Transitions de couleurs entre sections

Vous pouvez créer des transitions de couleurs entre des sections avec `data-parallax-color` :

### Exemple de transition verticale

<div style={{ position: 'relative' }}>
  <NxParallaxColorTransitions color="#FF0000" />
  <NxParallaxColorTransitions color="#4ecdc4" />
</div>
